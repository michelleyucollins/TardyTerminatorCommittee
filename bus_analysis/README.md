# bus_analysis Folder TLDR
This folder contains all basic analysis points and basic Neural Network structures done on the high confidence bus data - i.e. data which corresponding stops could be found at a high confidence rate. 

A total of 385k data points were used for this component of the analysis.

## ./basic_analysis/latlong_analysis.ipynb
This file performs basic analysis on the bus delays based on their latitude and longitude and gives a 3D graph of the data. 

## ./basic_analysis/time_analysis.ipynb
This file performs basic analysis on the bus delays based on their time. Multiple Linear Regression was used to establish a baseline model.

## ./basic_analysis/weather_analysis.ipynb
This file performs basic analysis on the bus delays based on the weather of the day the delay occured on. Multiple Linear Regression was used to establish a baseline model.
